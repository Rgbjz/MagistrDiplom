# Дизайн-система + тёмная тема + кабинет ученика — дизайн (подпроект A)

**Дата:** 2026-05-31
**Статус:** утверждён (дизайн), ожидает ревью спецификации

## 1. Цель и контекст

Поднять визуальный уровень платформы до современного SaaS («как Kwiga») и добавить **кабинет ученика** (дашборд). Это **подпроект A** из более крупного «Kwiga-like» апгрейда, разбитого на:

- **A (этот спек):** дизайн-система + тёмная тема + кабинет ученика.
- **B (позже):** лендинги курсов + цена (free/paid) + мок-покупка.
- **C (позже):** мок-подтверждение email при регистрации.

Порядок: A → B → C. B и C получают собственные spec → план → реализацию.

## 2. Зафиксированные решения

| Область | Решение |
|---|---|
| Визуальное направление | **Polished Blue** — эволюция текущего стиля (тёмно-синяя шапка, синий акцент `#2563eb`), но с SaaS-полировкой (мягкие тени, скругления, воздух) |
| Тёмная тема | Да, переключатель в шапке, выбор в `localStorage`, применяется до отрисовки |
| Технический подход | **CSS-переменные (токены)** в `globals.scss` + `[data-theme]`; SCSS-модули ссылаются на `var(--…)`. Без новых UI-фреймворков |
| Шрифт / иконки | **Inter** через `next/font`; **lucide-react** вместо эмодзи |
| Раскладка кабинета | **Одна колонка** (сверху вниз) |
| Главная `/` | Превращается в **дашборд**; старый список курсов → блок «Каталог» внутри него |
| Состояния | Скелетоны, пустые состояния, тосты; данные через TanStack Query |

## 3. Дизайн-токены и темизация

`frontend/src/app/globals.scss` объявляет CSS-переменные:

- **Цвета:** `--color-primary` (#2563eb), `--color-primary-hover` (#1d4ed8), `--color-bg`, `--color-surface`, `--color-text`, `--color-text-muted`, `--color-border`, `--color-success`, `--color-danger`, `--color-warning`, `--color-header` (#1e293b), `--color-header-text`.
- **Радиусы:** `--radius-sm/md/lg` = 6/10/14px.
- **Тени:** `--shadow-sm/md/lg`.
- **Отступы:** `--space-1…6` = 4/8/12/16/24/32px.
- **Типографика:** семейство Inter; `--font-size-xs…2xl`; веса.

**Тёмная тема:** те же имена токенов переопределяются под `[data-theme="dark"]` (тёмный фон/поверхности, светлый текст, тот же синий акцент). По умолчанию — системная тема (`prefers-color-scheme`), иначе светлая. Выбор хранится в `localStorage` и выставляется на `<html data-theme>` инлайн-скриптом **до первой отрисовки** (без «мигания»). Существующие SCSS-модули постепенно переводятся с хардкод-хексов на токены.

## 4. UI-кит (`frontend/src/components/ui/`)

Все примитивы на токенах (значит автоматически темо-зависимы):

- **Button** — `primary / outline / ghost / danger`, размеры, `loading` (спиннер), `disabled`.
- **Card** — поверхность (тень/радиус/фон-токены).
- **Input / Textarea / Select** — единый стиль + focus.
- **Badge** — статус-пилюли (Active/Pending/Free/цена).
- **Avatar** — картинка или инициал, размеры.
- **Skeleton** — заглушки загрузки.
- **Toast** — провайдер всплывающих уведомлений (успех/ошибка).
- **EmptyState** — иконка + текст + действие.
- **ProgressBar** — существующий, переведён на токены.
- **ThemeToggle** — переключатель темы (солнце/луна) для шапки.

## 5. Применение к экранам (объём подпроекта A)

Переводим на токены + UI-кит ключевые места; остальное — в следующих подпроектах.

- **Глобально:** `globals.scss` (токены, тёмная/светлая, Inter, focus-стили), инлайн-скрипт темы в `layout.tsx`.
- **Header:** ThemeToggle, выпадающее меню профиля с аватаром, активная подсветка раздела, иконки lucide, мобильное бургер-меню.
- **Footer:** под токены.
- **CourseCard:** обложка-градиент при отсутствии картинки, бейдж статуса, мини прогресс-бар, кнопки через `Button`.
- **Login / Register:** поля/кнопки через UI-кит (логика rhf+zod без изменений).
- **Кабинет** (новый, §6): целиком на новом ките.

**Не трогаем в A** (работают в старом стиле, переведём позже): страница курса, прохождение тестов, конструктор, управление, чат.

## 6. Кабинет ученика (дашборд)

**Маршрут:** главная `/` становится дашбордом. Ролевой экран.

**Студент (одна колонка):**
1. **Приветствие** — «Привет, {имя}» (имя из профиля, иначе email).
2. **Статистика** — 4 stat-карточки: курсов записан (ACTIVE) · завершено · уроков пройдено · средний балл тестов.
3. **«Продолжить обучение»** — карточки ACTIVE-курсов с прогрессом < 100%, прогресс-бар + кнопка «Продолжить» → `/courses/:id`. Пусто → EmptyState.
4. **«Каталог курсов»** — поле поиска (по названию/описанию) + грид всех курсов (обновлённый CourseCard).
5. **«Последние чаты»** — 3–5 последних бесед из `/chat/conversations` → `/chat`.

**Преподаватель (лёгкий):** приветствие + кнопка «Создать курс» + блок «Мои курсы» (которые ведёт) + каталог + последние чаты. Без статистики обучения.

**Состояния:** скелетоны по блокам, пустые состояния, тосты.

## 7. Изменения на бэкенде

1. **Новый `GET /api/dashboard`** (auth, ролевой) — модуль `DashboardModule`, переиспользует `ProgressService`/`PrismaService`:
   - **студент:** `{ stats: { enrolled, completed, lessonsCompleted, testsPassed, avgScore }, continueLearning: [{ id, title, imageUrl, percent }], recentConversations: [...3] }`
   - **преподаватель:** `{ teachingCourses: [{ id, title, imageUrl }], recentConversations: [...3] }`
   - Расчёт `stats`: `enrolled` = число ACTIVE-записей; `completed` = курсы с прогрессом 100%; `lessonsCompleted` = завершённые `LessonProgress`; `testsPassed` = число пройденных тестов; `avgScore` = средний балл по завершённым попыткам (`TestResult.score`, `finishedAt != null`). Прогресс по курсу = `ProgressService.getProgress`.
2. **Поиск в каталоге:** `GET /api/courses?search=<q>` — необязательный регистронезависимый фильтр по `title`/`description` в `CoursesService.getCoursesForUser`. Без пагинации.
3. **Чаты:** переиспользуем `GET /api/chat/conversations` (последние 3–5 берём на фронте/в dashboard-эндпоинте).

Новых таблиц нет.

## 8. Вне скоупа подпроекта A

- Лендинги курсов, цена, покупка (подпроект B).
- Подтверждение email (подпроект C).

- Геймификация (стрики/бейджи), сертификаты, уведомления-лента.
- Пагинация каталога.

## 9. Критерии готовности

- Тёмная/светлая тема переключается без «мигания», выбор сохраняется.
- UI-кит используется в шапке, карточках курса, формах входа/регистрации и кабинете.
- Главная `/` = дашборд: для студента — статистика + «Продолжить» + каталог с рабочим поиском + последние чаты; для преподавателя — мои курсы + создать + каталог + чаты.
- Скелетоны/пустые состояния/тосты работают.
- Существующие экраны (курс, тесты, конструктор, чат) продолжают работать (в старом стиле).
