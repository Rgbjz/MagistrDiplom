# UI-тесты (Playwright)

74 сценария, которые проходят интерфейс так же, как пользователь: открывают страницы в Chrome, кликают, заполняют формы.

| Файл | Что проверяет |
|---|---|
| `guest.spec.ts` | главная, каталог (поиск, фильтры, сортировка), лендинг курса, 404, тема, редиректы |
| `auth.spec.ts` | регистрация с подтверждением email, ошибки входа, повторная отправка письма, сброс пароля, выход |
| `student.spec.ts` | кабинет, «Мої курси», сертификат, уроки, файлы и видео урока, тест и результат, оплата, заявка, уведомления, чат, профиль, доступы |
| `teacher.spec.ts` | кабинет преподавателя, мастер курса, конструктор (видео, файлы, тесты), публикация, одобрение заявки, управление курсом, чужой курс |
| `admin.spec.ts` | статистика, пользователи (поиск, фильтр, пагинация), смена роли, блокировка, курсы, платежи |
| `call.spec.ts` | видеозвонок в двух браузерах с фейковыми камерой и микрофоном: звонок, ответ, видео идёт, индикатор выключенного микрофона, завершение; отклонение; вход через баннер «Приєднатися до дзвінка» |

| `mobile.spec.ts` | Pixel 7: нижнее меню, шторка содержания курса, тест на телефоне, чат |

## Запуск

Нужны запущенные бэкенд и фронтенд с демо-данными. Почта должна быть в режиме разработки (`SMTP_HOST` пустой), тогда токены подтверждения приходят в ответе API.

```bash
cd backend && npm run db:seed            # демо-данные (можно запускать повторно)
cd frontend
E2E_BASE_URL=http://localhost:3000 E2E_API_URL=http://localhost:5000/api npm run test:e2e
npm run test:e2e:report                  # HTML-отчёт со скриншотами и трейсами упавших тестов
```

По умолчанию адреса `http://localhost:3055` и `http://localhost:5055/api`.
Тесты используют установленный Google Chrome (`channel: 'chrome'`): встроенный Chromium Playwright не поддерживает macOS 12.
Тесты создают собственных пользователей и курсы, поэтому их можно запускать повторно без сброса базы.
